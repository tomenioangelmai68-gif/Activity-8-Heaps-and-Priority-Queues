# Activity 8 - Heaps and Priority Queues

## Description
This repository contains Python implementations of heaps and priority queues.

## Completed Activities

1. **Min-Heap** - Implements insert, peek, extract, and size operations.
2. **Max-Heap** - Implements a heap that prioritizes the largest value.
3. **Heap Sort** - Sorts numbers using a Max-Heap.
4. **Kth Largest** - Finds the kth largest number using a Min-Heap.
5. **Merge K Sorted Arrays** - Combines three sorted arrays using a Min-Heap.
6. **Priority Scheduler** - Releases jobs according to their priority.

## Testing
The implementations include tests for:
- Empty structures
- Single elements
- Duplicate values
- Longer random sequences

## How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Open the terminal in the project folder.
4. Run:

```bash
python activity8_heaps.py
```
